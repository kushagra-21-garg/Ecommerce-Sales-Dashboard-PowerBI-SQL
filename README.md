# E-Commerce Sales Dashboard | Power BI & SQL

## Project Overview

## Tools Used
- Power BI
- SQL
- Excel

## Key Metrics
- Sales Amount
- Profit
- Quantity
- Average Order Value (AOV)

## Features
- Interactive Dashboard
- Sales Trend Analysis
- Category & Payment Mode Analysis
- Business Insights
